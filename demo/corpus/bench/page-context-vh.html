100vw × 10vh band

Benchmark for CORE-140 (page-context enablers). The dark band sizes itself with viewport units. In print context, vh/vw must resolve against the PAGE box — before CORE-140 lands, stylo's fixed 1024×768 viewport is used instead, so the band's height is wrong for this 5in×3in page (10vh of 768px ≈ 76.8px ≈ 57.6pt, versus 10vh of the 216pt page = 21.6pt).

Ground truth: the band's height is 21.6pt (10% of the 3in page height), spanning the full 4in content width.
