Foundations

Background

This report examines the load-bearing assumptions behind the Northwind platform and the evidence gathered over the third quarter. The foundations chapter sets out the terminology and the measurement conventions used throughout, so that every subsequent figure is comparable.

Each chapter begins on its own page. Running headers carry the current chapter name into the top margin, page numbers sit centered at the bottom, and the table of contents at the front resolves each entry to the page where its chapter begins, with dotted leaders filling the space between the title and the number.

Scope

The scope is deliberately narrow: only the paged-media behaviors a typesetting engine must reproduce to render a professional report are considered. Everything else is out of band for this quarter.

Methods

Procedure

The procedure followed a fixed protocol applied identically across all trials. Determinism was verified by re-running each case and comparing the byte output, which must be identical for the run to count.

Instrumentation was kept minimal to avoid perturbing the measured quantities, and every derived figure is traceable to a raw observation recorded at ingest time.

Materials

Materials were sourced from a single deterministic generator so that the inputs themselves never varied between runs of the experiment, making the reported numbers directly comparable across quarters.

Findings

The findings confirm the central hypothesis: running headers, page numbers, and cross-referenced page numbers can all be produced in a single bounded set of layout passes without sacrificing determinism, and the improvement in render time came from the fragmentation core, not from faster I/O. The full methodology is documented in the Methods chapter, and the discussion of what the numbers mean continues in the Discussion chapter; the underlying data files are published at northwind.example/q3-data.

Discussion

Interpretation

The results are consistent with the plan: fragmentation-first layout pays for itself once documents exceed a single page. The table above fragments cleanly across page boundaries when it must, and its header repeats on each page, exactly as a printed financial report requires.

We close the quarter on track against the roadmap, with the engine now producing professional documents end to end: cover, contents, chapters, running content, and cross-referenced page numbers.
