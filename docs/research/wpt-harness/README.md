# WPT Research Archive Index

The issue-specific WPT studies formerly stored in this directory are preserved
in the external TypeAnvil documentation archive. They contain dated test
results, private artifact paths, and issue coordination. Current public harness
rules live in [WPT Print-Reftest Harness Research](typeanvil-wpt-harness-brief.md)
and the [WPT Conformance Harness specification](../../specifications/wpt-conformance-harness.spec.md).
