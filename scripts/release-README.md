Typeanvil — AI-first HTML/Markdown to PDF typesetting engine

This archive contains the standalone `typeanvil` binary for your platform.

Quick start:

    ./typeanvil --help
    ./typeanvil render input.html -o output.pdf

Install (Node.js/Bun): `npm install -g typeanvil` (see the npm package).
Install (macOS): `brew install whitelodge/tap/typeanvil` (see the Homebrew tap).

Typeanvil is open source under AGPL-3.0-only.
