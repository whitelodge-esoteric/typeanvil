## Mechanics

- **No signing ceremony.** Opening a PR = agreeing to these terms. The PR
  template links back here.
- **Sign-off line.** Each commit should end with:
  `Signed-off-by: Your Name <your.email@example.com>`
  (`git commit -s`). This certifies authorship and consent; it is not a
  substitute for the terms above.
- **Employer-owned code:** if your employer owns the code, contact the
  maintainer before contributing so a corporate arrangement can be made.
