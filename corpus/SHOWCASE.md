# TypeAnvil Showcase

Print-resolution renders (US Letter @ 300 DPI) are no longer committed to this
repo (CORE-495). Every release publishes them to the public
[typeanvil-showcase](https://github.com/whitelodge-esoteric/typeanvil-showcase)
repo, also served on its
[Pages site](https://whitelodge-esoteric.github.io/typeanvil-showcase/).

To render locally, run `scripts/build-showcase.sh`. Output goes to the ignored
`corpus/out/showcase/` tree. See `docs/operations/showcase.md`.
